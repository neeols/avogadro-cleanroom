Client-only Scala presentation tools sharing Avogadro's renderer and export engine. Keep this import in client proxies and screens. Never reference it from a dedicated-server entry point. Camera, styling and time do not alter chemistry.

def exportMedia(request: Builder)(configure: Builder => Unit): ExportJob

Completes a typed request and submits it on the client thread.

Completes a typed request and submits it on the client thread.

Value parameters

configure

set export options, rendering style and realization metadata on the shared builder

request

start with MediaExportRequest.molecule, molecules, item, atom or polymer

Attributes

Returns

job-specific progress, cancellation and retained terminal result

Throws
java.lang.IllegalStateException

if another export is active or submission is on the wrong thread

Note

No queue or retry is added. Completion listeners run exactly once on the client thread after cleanup; late listeners receive the retained result. Listener errors cannot change the export outcome. The job never cancels a later export.

object Avogadro

Scala 3 functions for creating molecules, editing copies, and registering your mod's definitions.

Import io.github.wurtzitane.avogadro.scala.Avogadro. Each block receives the builder, an object on which you choose atoms, bonds, matches and inspection details before creating a definition. No registration happens while building it. Common-side code can use this object without loading the client. The host supplies Scala 3 through Scalar; Scalar Legacy's Scala 2.11 runtime cannot execute these helpers.

val water = Avogadro.molecule("mymod:water") { m =>
 m.name("Water").smiles("O").fluids("water")
}
Avogadro.register("mymod", water)

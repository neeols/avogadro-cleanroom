AvogadroCoroutines

object AvogadroCoroutines

Optional coroutine helpers. Only callers of this object need kotlinx-coroutines-core. The normal Kotlin facade and Java/Scala consumers do not load this class.

Cancellation stops waiting; it does not cancel preparation, undo publication, or release an owner. Keep a RegistrationJob and call its explicit cancel/release methods when managing its lifetime. Continuations resume through their coroutine context; this object never chooses a game dispatcher.

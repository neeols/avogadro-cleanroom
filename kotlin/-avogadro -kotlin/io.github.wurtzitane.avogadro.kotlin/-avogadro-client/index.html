AvogadroClient

object AvogadroClient

Client-only Kotlin presentation helpers. Keep imports and calls in your client proxy or screen. They share the Java renderer, viewport clipping, export validation and job engine. They never create another definition or alter stored geometry.

fun exportMedia(request: MediaExportRequest.Builder, configure: MediaExportRequest.Builder.() -> Unit): ExportJob

Finishes and submits an existing typed request builder on the client thread. Start with MediaExportRequest.molecule, molecules, item, atom or polymer. configure exposes export size, GIF/MP4 options, render style and exact realization metadata. Returns the engine's job-specific progress, cancellation and completion handle. A busy engine rejects the request; this helper does not queue or retry it. Completion listeners run once on the client thread after cleanup, including late listeners.

fun render(structure: MoleculeStructure, x: Int, y: Int, width: Int, height: Int, options: MoleculeRenderOptions = MoleculeRenderOptions.builder().build(), elapsedSeconds: Double = 0.0)

Draws structure in a rectangular viewport on the render thread. elapsedSeconds is caller-owned animation time; reuse it for reproducible rotation. options affects only this draw, so simultaneous screens can use independent styles. Use MoleculeRenderOptions.builder() for palettes, camera, sizes and background.
